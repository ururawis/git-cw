Explicación de un Código en C usando HTML

Código: 


        #include 
        int main() {
            int edad;
            printf("¿Cuántos años tienes? ");
            scanf("%d", &edad);

            if (edad >= 18) {
                printf("Eres mayor de edad.\n");
            } else {
                printf("Eres menor de edad.\n");
            }
            return 0;
        }

¿Qué hace el programa?

El programa le pregunta al usuario su edad, una vez que el usuario ingresa su edad el programa le indica si es mayor o menor de edad.

Explicación paso por paso

#include <stdio.h>; es la biblioteca que se está usando, maneja la entrada y salida de datos.

int main(){...} Es la función principal a partir de aquí comienza el código, el contenido se escribe entre corchetes {}.
Devuelve un número entero, en este caso 0, para indicar que que el programa ha finalizado correctamente, en el código se ve como return 0;

int edad; Declara la variable edad de tipo entero

printf("¿Cuántos años tienes? "); Imprime en la terminal la pregunta y con scanf("%d", &edad); recibe el dato que escribe el usuario y lo guarda en la variable edad.

Con el bloque:


            if (edad >= 18) {
                printf("Eres mayor de edad.\n");
            } 
            else {
                printf("Eres menor de edad.\n");
            }
Comprueba si el dato edad es mayor o igual a 18, si lo es en la terminal imprime que se es mayor de edad y si no lo es muestra que se es menor de edad.
